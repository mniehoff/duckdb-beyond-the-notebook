# duckdb beyond the notebook

Various demos for duckdb usage beyond analytics in a notebook

# backend
Run a data analytics application, duckdb in the Rest API Backend

# lambda
Data transformations in a lambda

# mcp
DuckDB MCP to give agents analytics capabilities

# server
Run duckdb in a server, store data in ducklake and use quack as protocol to connect to it

# spark
Run existing spark applications on duckdb - by adding a two-liner

# wasm
Run a data analytics application, duckdb in the Browser
